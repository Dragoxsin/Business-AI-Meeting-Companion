# IBM Generative AI Applications with Python

A collection of practical Generative AI applications developed as part of my IBM training. This repository demonstrates how to integrate LLMs, speech-to-text processing, and audio analysis using Python.

## 🚀 Projects Included

*   **Speech Analyzer (`speech_analyzer.py` / `speech2text_app.py`):** Converts audio recordings into structured text and extracts key information using AI.
*   **Simple LLM (`simple_llm.py`):** A basic pipeline demonstrating prompt engineering and text generation.

## 🛠️ Tech Stack & Tools

*   **Language:** Python
*   **AI Models & Frameworks:** IBM Watsonx / Generative AI SDKs
*   **Libraries:** `os`, `dotenv` (for secure credential management)

## 🔒 Setup Instructions

1. Clone this repository:
   ```bash
   git clone https://github.com
   ```
2. Install dependencies:
   ```bash
   pip install python-dotenv
   ```
3. Create a local `.env` file in the root directory and add your API keys:
   ```text
   IBM_API_KEY=your_secret_key
   ```
